 Survey Feedback Analyzer 

The Survey Feedback Analyzer is a beginner-level Python project designed to analyze customer survey responses and extract meaningful insights from written feedback.
This project focuses on organizing customer feedback, cleaning unstructured text, identifying frequently used words, and generating useful summary statistics.
It demonstrates how basic Python programming concepts can be applied to a real-world feedback analysis scenario.

 Objectives
 
• Store survey responses using a dictionary of lists.
•	Collect additional feedback dynamically from users.
•	Clean text by removing punctuation and unnecessary spaces.
•	Convert feedback into lowercase for consistent analysis.
•	Identify feedback containing specific keywords.
•	Calculate the average customer rating.
•	Find the longest feedback comment.
•	Extract unique words from all feedback entries.
•	Sort feedback records based on customer ratings.

1. Preloaded Survey Data

Created a dictionary of lists containing 10 predefined customer feedback records, including serial numbers, customer names, written comments, and ratings.

2. Adding New Feedback

Collected additional customer responses through user input and dynamically updated the existing dictionary using loops and the append() method.

3. Text Cleaning

•	Removing punctuation marks.
•	Eliminating extra spaces.
•	Removing leading and trailing spaces.
•	Converting feedback into lowercase.

4. Word Count Insights

Developed a user-defined function count word in feedbacks to identify how many feedback entries contain specific keywords such as:
•	Good
•	Poor
•	Excellent

5. Final Summary & Insights

•	Displayed the final cleaned dictionary.
•	Calculated the average customer rating.
•	Identified the feedback with the highest word count.
•	Extracted unique words without duplicates.
•	Sorted feedback entries based on ratings (highest to lowest).
